# Katalog UMKM Sekar Jagad Solo

Katalog produk dinamis berbasis PHP (Pertemuan 7 Pemrograman Web).

## Cara Menjalankan
1. Salin folder ke htdocs/ atau www/ Laragon.
2. Nyalakan Apache.
3. Buka http://localhost/katalog-umkm/

## Fitur
- Kartu produk ditampilkan menggunakan foreach.
- Label stok menggunakan match(true).
- Filter kategori melalui URL.
